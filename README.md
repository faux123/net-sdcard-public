# Net SD card

Net SD card lets the emulators on your Android phone or handheld play the games stored on your PC, as if they were on an SD card. Games download when you open them and the app clears the oldest ones when space runs low. No root is needed.

- **Get it:** Net SD card is moving to Google Play. Downloads here have ended. Product page and user manual: https://netsd.canonspike.com
- **Report a problem:** open an issue here, or use **Troubleshooting** > **Send a bug report** in the app.

The source code is closed. This repository holds the issue tracker.
